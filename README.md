# Pragmatic Audio PEQ: downloads

System-wide parametric EQ for headphones. Load a headphone profile (OPRA, AutoEq and measurement sites), edit it, and hear it on
everything you play. Made by [Pragmatic Audio](https://buymeacoffee.com/pragmaticaudio).

This repository only holds the **downloads** (see Releases). The source is not published here.

| Platform | Download | Notes |
|---|---|---|
| macOS | the `.dmg` in the latest `macos-v*` release | Open it and drag the app to Applications. The first launch installs the audio driver ("Pragmatic EQ") and asks for permission. |
| Windows 11 | the `.exe` installer in the latest `windows-v*` release | Installs the app and an audio processing object, then turn it on for your headphones in Settings > Windows audio. Early release. |
| iPhone and iPad | TestFlight / App Store | |

The Mac app checks this page once a day and tells you when a newer version is out.
